# Sunny Gogikar — Developer Portfolio

A responsive dark-themed developer portfolio built with plain HTML, CSS, and JavaScript. No package installation or build step is required.

## Files
- `index.html` — page content and project cards
- `styles.css` — responsive layout, colors, and visual design
- `script.js` — mobile navigation and current year

## Deploy to Vercel using GitHub
1. Sign in to GitHub and create a new **public** repository, for example `sunny-developer-portfolio`.
2. On the repository page, choose **Add file → Upload files**.
3. Upload `index.html`, `styles.css`, `script.js`, and `README.md` from this folder. Upload the files themselves, not just the ZIP.
4. Click **Commit changes**.
5. Sign in to https://vercel.com/ and choose **Add New → Project**.
6. Import the `sunny-developer-portfolio` repository and click **Deploy**.
7. This is a static website. If Vercel asks for configuration, select **Other** as the framework preset, leave Build Command empty, and use `.` as the output directory if required.
8. After deployment, click the generated `*.vercel.app` URL.

## Personalize before sharing
Open `index.html` on GitHub and click the pencil icon to edit:
- Replace the generic GitHub and LinkedIn links with your real profile URLs.
- Replace `YOUR_EMAIL@example.com` with your professional email address.
- Each project card currently links to the generic GitHub homepage. Replace each `href="https://github.com/"` with that project's real repository or demo URL.
- Add your resume PDF by uploading it to the repository, then add a link to it in the page if desired.

## Notes
- The portfolio uses a Google Fonts import, so the font may fall back to system fonts if external font access is blocked.
- Only list skills and project features you can confidently explain to an interviewer.
